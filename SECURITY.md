# Security

## Reporting

Email `security@dlab5.net` or open a private security advisory on this
repository. Please do not open a public issue for a suspected vulnerability.

## This repository is public

Everything committed here is world-readable, forever, including anything later
deleted — `git` keeps history. The rules below are not advice, they are the
contract.

**Never commit**

| Category | Notes |
|---|---|
| `amplify_outputs.json` | Gitignored. Holds the Cognito user-pool and identity-pool IDs, the AppSync endpoint and the S3 bucket name. Not secrets, but a free reconnaissance map. It is regenerated by `ampx sandbox` / `ampx pipeline-deploy`. |
| AWS account IDs and ARNs | Including in ADRs, comments and commit messages. Refer to resources by logical name. |
| Any `.env` file | `.env.example` with empty values is the only exception. |
| Access keys, session tokens, private keys | GitHub push protection will usually stop you. Do not rely on it. |
| Real people's emails, internal hostnames, customer names | Especially in seed data and ArchiMate models — an ABox is exactly the kind of file where a real org chart accidentally ends up. |

**`GATSBY_`-prefixed environment variables are public.** Gatsby inlines them
into the JavaScript bundle at build time. A secret behind a `GATSBY_` prefix is
a published secret. Anything that must stay private belongs in a Lambda's
environment, not the frontend's.

## Design invariants

These are properties the code is meant to have. If a change breaks one, that is
a security bug, not a refactor.

1. **No guest access anywhere.** The Cognito identity pool has
   `allowUnauthenticatedIdentities = false`, the AppSync API has no API key and
   no `identityPool` default mode, and no model carries `allow.guest()`.
2. **No self-signup.** The user pool sets `allowAdminCreateUserOnly = true`.
   Hiding the sign-up tab in the UI is not the mechanism.
3. **Authorization is server-side.** UI checks like "is this user in
   `bp-<slug>`" are for ergonomics. The real check happens in the AppSync
   authorization rules and in the storage-proxy Lambda. A page that hides a
   button is not a control.
4. **The browser never talks to S3 directly.** Model reads and writes go
   through `requestModelReadUrl` / `requestModelWriteUrl`, which check the
   caller's Cognito groups against the project's group and return a short-lived
   pre-signed URL.
5. **Static output contains no authenticated data.** `gatsby-ssr` neither
   configures Amplify nor mounts the auth gate; every project byte is fetched
   in the browser after sign-in.

## Auditing

Run the `dhc-security-audit` skill against this repo before each production
deploy and file the report under `docs/audits/YYYY-MM-DD-audit.md`. It covers
secrets and git-history scanning, Cognito/AppSync authorization coverage,
dependency and licence hygiene, build and CI configuration, and GitHub posture.
